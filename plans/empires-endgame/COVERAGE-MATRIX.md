# Empire's Endgame — scope and ownership matrix

This is the closure ledger for the completion program. It prevents content that is absent
from the current config from disappearing between phase prompts. Update it whenever a raw
source, config carrier, designer verdict, or phase boundary changes.

Status meanings:

- **Complete** — shipped before or during the current program; later phases only regress it.
- **Owned** — guaranteed substrate/change-set owner.
- **Conditional** — the owner reconciles it, but it stays deferred when semantics or a
  required substrate remain undefined.
- **Review** — present in raw intent but not confirmed for this tranche; do not implement
  until the designer supplies a verdict and an owner.
- **Out** — explicitly outside the confirmed 2026-07-16 scope.

The completed P12B machine manifest uses the finer dispositions `live`,
`blocked-semantic`, `blocked-substrate`, `review`, and `out`. `ready-now` is a transitional
audit state only: the final manifest contains none. Blocked/review rows are owned by a
future content tranche after the missing semantics or substrate receive a designer verdict;
P13 did not acquire them. The maintained source spine freezes `1,149` JSON-export message
IDs across the 33-entry source inventory and requires residual review/out ownership for each
source. Stable raw semantic identities are a separate manually reviewed inventory; the
machine check detects drift in the maintained spine but does not infer new concepts from raw
prose. The extensionless prompt, population PNG and parent-message `Palach`/`Palach2`,
`EE_TD`, `EE_chest` and semantic text attachments are manually inspected and explicitly not
content-digested by the 1,149-ID spine. A maintained source/raw projection fingerprint pins
same-count message substitutions and exact raw→config links without claiming raw-file
discovery.
