## 1. Глоссарий

| Термин | Определение |
|--------|-------------|
| **Палуба** (deck) | Секция корабля со своей прочностью. Корабль состоит из 1–4 палуб. |
| **Прочность** (armor) | Сколько урона выдерживает палуба до уничтожения. По умолчанию = 2. |
| **Space** | Радиус клеток вокруг корабля, в котором нельзя ставить другие корабли. По умолчанию = 1, максимум = 2. Также используется для пассивок (заморозка, разведка, просветка при убийстве). |
| **Класс дальности** | Определяет правила размещения и стрельбы корабля: Close, Close (melee), Mid, Tetra, Far. |
| **Активка** | Особый выстрел (не обычная баллиста), использует ход вместо обычного выстрела. |
| **Сумон** | Призываемый юнит на вражеское поле. Призыв не тратит ход. |
| **Выстрел** (shot) | Единица времени. Считаются суммарно для обоих игроков. |
| **Ход** (turn) | Очередь игрока. Может включать несколько выстрелов при ресетах. |
| **Ресет хода** | Продолжение хода после уничтожения вражеской палубы. |
| **Просвеченная клетка** (revealed cell) | Клетка на вражеском поле, содержимое которой было раскрыто. Максимум = 100. |
| **Домашний юнит** | Метка, которая сейчас влияет только на определение первого игрока. Ограничения половины поля пока нет. |
| **Burn** | Статус — мгновенное сгорание всего корабля. |
| **Freeze** | Статус — заморозка, выключает корабль/сумона из игры. |
| **Devastated** | Статус — опустошение, выключает корабль из игры (аналог freeze, чёрная окраска клеток у обоих игроков). Вражеская Пиратская лодка захватывает такой корпус любого размера, собственная может полностью его восстановить. |
| **Capture** | Статус — обязательная цель исходного владельца; подробный жизненный цикл в §4. |
| **Destroy** | Статус — уничтожение палубы с выключением модуля на ней. |
| **Stun** (оглушение) | Статус — пропуск хода, срабатывает в течение 1–2 выстрелов. |
| **Penalty** (штраф) | Статус — пропуск следующего хода, без срока давности. |
| **Burn resist** | Статус — иммунитет к сгоранию. |
| **Электрический заряд** | Постоянный статус клетки от успешного попадания Нептуна; три новые метки одного орудия на одном физическом поле образуют бирюзовый треугольник. |

## 2. Обзор

### Core Loop

1. **Выбор армии** — Империя или Альянс.
2. **Расстановка и апгрейды** — размещение кораблей на поле 10x10 + распределение бюджета армии: 40 монет у Империи, 50 у Альянса.
3. **Бой** — пошаговая стрельба с ресетами, активками и сумонами.
4. **Финальный абордаж** — один глобальный переход, когда у любой стороны кончаются живые Mid; сервер навсегда фиксирует одну атакующую сторону, и второй игрок ни при каких последующих потерях Mid не начинает собственный абордаж.

### Фракции

- **Империя** — армия с Тетранависом и имперскими улучшенными кораблями.
- **Альянс** — армия с бесплатным **Обычным Четырехпалубником** 2/2/2/2, Баллистой на каждой палубе и Мачтой на второй, а также платными альтернативами, включая диагональный корпус, Русскую Матрешку и обе версии разогревающегося/сливающегося корабля.
- **Общие** — доступны всем армиям.

Набор и правила обычных сумонов у Альянса полностью совпадают с Империей; доступность Тарана/Разведчика/Пиратской лодки по-прежнему определяется регионами выбранного флота.
Алхи-баржа, Горючая баржа, Маневрирующая двойка и Пираты доступны обеим армиям.

### Регионы

4 региона: Юг, Запад, Север, Восток. Игрок может использовать корабли максимум из **3 регионов из 4**. Корабль с несколькими регионами занимает каждый указанный слот. Регион **Тетракор** — внутренний тег, который не учитывается в ограничении.

## 3. Основные механики

### 3.1. Структура хода

```
Начало хода игрока
├─ Обязательная сборка Заслуженного собирающегося корабля, если из трёх частей жива ровно одна
├─ Обязательный манёвр повреждённого manual_move_after_hit-корабля
│  ├─ Есть легальные конечные клетки → все остальные действия заблокированы до выбора клетки
│  └─ Нет легальных клеток → этап автоматически пропущен
├─ Призыв сумона (опционально, не тратит ход, макс 1 за 2 выстрела)
├─ Выбор действия:
│  ├─ Есть живой Mid/Close с живой Баллистой на живой палубе?
│  │  ├─ Да → Выстрел Баллистой доступен
│  │  └─ Нет → Выстрел Баллистой НЕ доступен
│  ├─ Есть снаряды у активок?
│  │  ├─ Да → Активка доступна
│  │  └─ Нет → Активка НЕ доступна
│  └─ Ничего не доступно → проверка условий поражения (см. раздел 10)
├─ Выстрел по вражеской карте
│  ├─ Попадание в палубу вражеского корабля
│  │  ├─ Палуба уничтожена → РЕСЕТ (стреляй ещё)
│  │  └─ Палуба выжила (броня > 0) → ХОД ПРЕРВАН ("Поцарапал броню!")
│  ├─ Повторный выстрел в уже уничтоженную палубу → ХОД ПРЕРВАН
│  ├─ Попадание в обычного сумона → ХОД ПРЕРВАН (+ возможный штраф, см. «Штраф при убийстве сумона»)
│  └─ Промах (пустая клетка) → ХОД ПЕРЕДАН врагу
└─ Выстрел по своей карте (вражеский сумон, Греческий огонь/Злой Греческий огонь или обязательный CAPTURE)
   ├─ Обычный сумон, последняя палуба абордажного корпуса либо CAPTURE → собственного ресета нет
   ├─ Уничтожена промежуточная палуба живого вражеского абордажного корпуса → собственный РЕСЕТ
   └─ Выстрел по собственному абордажному корпусу всегда завершает ход
```

«Ход прерван» и «собственного ресета нет» описывают результат самой цели. Живая независимая серийная пассивка вроде разогрева или двойного выстрела может отдельно сохранить ход. Исключение — выстрел по собственному абордажному корпусу: его `ForcesTurnEnd` имеет приоритет над любой серией.

Во время Финального абордажа игрок без легального выстрела получает действие **«Двигать призывы / Пас»**: призывы двигаются один раз, затем ход передаётся сопернику. Это действие не является выстрелом и не даёт ресет.

После попадания, которое сохраняет ход, следующий выстрел того же игрока блокируется на **8 секунд**, только если обстреливаемый игрок — **человек** и сервер прямо сейчас допускает размещение хотя бы одного его сумона. Если у защитника исчерпан лимит, не достигнут порог разведки, действует перезарядка сумонов, нет свободной легальной клетки входа, размещение закрыто другой обязательной стадией либо поле принадлежит боту, reset-пауза равна **2 секундам**. Это серверное окно оставляет обстреливаемому человеку время выпустить сумона на вражеское поле между reset-выстрелами; выпуск разрешён вне своего хода, а игровой lock всё это время свобождён. В то же окно защитник с Злым Греческим огнём может выстрелить им по своей доске, не передавая и не присваивая текущий ход. После промаха паузы нет: если никакая иная механика не сохранила серию, ход передаётся немедленно. Когда разрешённый выстрел человека оставляет ход у того же человека, V2/V3 получает не более одного собственного окна реакции перед его следующей атакой. Сюда входит и сохраняющий серию промах Альянса: такое окно не имеет reset-таймера, поэтому в нём доступны только сумон или Пиратское восстановление, но не Злой Греческий огонь. Если выстрел уже передал ход боту, начинается его обычный ход, а не отдельная внеходовая реакция. Реакция привязана к глобальному номеру разрешённого выстрела, а не к наличию reset-таймера, поэтому её нельзя повторить в цикле. Бот обрабатывает не более одного выстрела или одного действия реакции за шаг и ждёт выбранную сервером паузу с освобождённым lock. Продолжение бота запускается фоново после возврата исходного SignalR-вызова, поэтому новый запрос защитника на выпуск сумона не сериализуется за всей серией выстрелов.

Полное уничтожение любой стадии Русской Матрешки приостанавливает текущее разрешение **до** движения сумонов, проверки Финального абордажа, победы и смены хода. Владелец обязан выбрать один из двух подсвеченных корпусов следующей стадии; пока выбор не сделан, все остальные действия обоих игроков заблокированы. После постановки сервер возобновляет ровно то же прерванное разрешение с сохранённым результатом reset/передачи хода. Если одним эффектом уничтожено несколько Матрешек, обязательные выборы выдаются последовательно; бот использует тот же барьер.

### 3.2. Урон и броня

- Урон обычной баллисты = **2**.
- Прочность обычной палубы = **2**.
- При остатке прочности > 0 — "Поцарапал броню!", ход прерывается. Палуба закрашивается особым цветом (коричневый).
- При прочности = 0 — палуба уничтожена.
- Броня не уходит ниже нуля.
- Все значения — целые числа, максимум 9.

**Специальный урон:**

| Снаряд | Значение |
|-----------|----------|
| Белый камень | 8 (базовые 2 × 4) |
| Дробь | 1 (базовые 2 × 0.5) |

Белый камень разрушает модуль поражённой палубы, даже если палуба с 9 HP пережила 8 урона. Каждая валидная посадка, кроме выстрела по CAPTURE-кораблю, накладывает Stun: обычно на владельца физической доски, но при выстреле по своей доске во вражеский абордажный корпус — на владельца этого корпуса. Выстрел Белым камнем по своему CAPTURE-кораблю не даёт Stun никому.

**Виды брони:** текущая броня и первоначальная броня — отслеживаются отдельно (для будущих механик).

Владелец видит точную текущую/максимальную прочность своего флота. Соперник видит только состояния неизвестно/цело, поцарапано и уничтожено, если отдельная механика не раскрывает больше.

### 3.3. Дальность

| Класс | Размещение | Стрельба | Абордаж | Примечания |
|-------|-----------|----------|---------|------------|
| **Close** | Строки 1–8 | Баллиста, пока живы корабль, её палуба и модуль | Да, только с живым носом | Живой Close с живой Баллистой позволяет обычный выстрел; уничтоженная палуба №1 исключает корабль из конверсии |
| **Close (melee)** | Строки 1–8 | 0 снарядов, не стреляет вообще | Да, только с живым носом | Если остались только Close (melee) — обычные выстрелы невозможны; уничтоженная палуба №1 исключает корабль из конверсии |
| **Mid** | Строки 1–8 | Баллиста, пока живы корабль, её палуба и модуль | Нет | Конец Mid у любой стороны запускает один глобальный финальный абордаж |
| **Tetra** | Где угодно, включая строки 9–10 | Активки (снаряды) | Нет | Палубы не выходят на 7–8 строки при постановке на 9–10. Артиллерия |
| **Far** | Где угодно, включая строки 9–10 | Активки (снаряды), но с 9–10 строки не достаёт до 9–10 вражеского поля | Нет | Прицел красный = не выстрелить. Артиллерия |

Tetra и Far — оба считаются **артиллерией**.

### 3.4. Передвижение

Три типа передвижения:

1. **Абордаж** — сумоны и абордажные корабли ставятся на 1-ю строку вражеского поля. Двигаются вниз, проходя за каждый выстрел столько клеток, сколько имеют скорости. Клетка появления и каждая конечная клетка шага проходят тот же порядок Grab → огонь → Freeze → столкновение с живой палубой → яд → разведка. Любой **Таран**, включая абордажный корабль, после достижения края можно вернуть в обратном направлении через соседнюю входную клетку. Пока хотя бы один Таран ждёт разворота, владелец обязан выбрать конкретный ожидающий Таран и вернуть его; выпуск другого обычного или ожидающего сумона заблокирован. Сумоны остальных типов после выхода за край покидают поле окончательно.

2. **Автоматическое** — Тройка из лёгкого дерева. Только при попадании **Баллисты** в нос или корму корабль автоматически отплывает в противоположную сторону, если новая позиция целиком находится на поле и сохраняет требуемый Space до каждого союзного корабля. Дробь, Белый камень и все огненные снаряды уклонение не запускают. Если направление нелегально, уклонения нет. Корабль заплывает в огонь/яд автоматически — игрок не может остановить. Успешное уклонение преобразует исходную клетку в чистую раскрытую воду с «Промахом» и **розовой** отметкой уклонения: на ней не остаётся белой, красной или жёлтой отметки палубы. У каждого такого корабля хранится только его последняя розовая клетка; новое уклонение стирает прежнюю, а смерть корабля убирает её полностью. После любого скрытого перемещения точное состояние палубы владельца берётся из её текущего HP, а сопернику не переносятся на новую палубу старые красные, жёлтые или разведанные состояния клетки. Уже раскрытая вода в месте назначения сама по себе не проявляет прибывший корабль.

3. **Мануальное** — Маневрирующая двойка, Знаменитый Врезающийся корабль и Сливающийся корабль Ver.2. После убийства палубы корабль в начале **своего** хода обязан выбрать один из легальных сдвигов на 1–2 клетки по своей оси; каждая дистанция проверяется отдельно. Обычная Маневрирующая двойка должна сохранить Space до всех союзников. Если вариантов нет, этап автоматически пропускается; иначе до выбора ярко-зелёной конечной клетки весь остальной интерфейс заблокирован и затемнён. Работает один раз **на каждый экземпляр корабля**. Знаменитый Врезающийся корабль — исключение: может войти в Space союзника и полностью удалить перекрытую палубу вместе с её модулем и оружием. Она не раскрывается сопернику и перестаёт входить в геометрию корабля: 4 палубы становятся 3, 2 становятся 1, а лишившийся единственной палубы либо последней живой палубы корабль удаляется без новой отметки потопления. Сливающийся корабль Ver.2 тоже может войти в Space и палубу любого союзника, включая Single и Собирающуюся палубу, но вместо структурного удаления всегда создаёт Уютный Совместный корабль; поглощённая Собирающаяся палуба больше не участвует в будущей сборке. Когда оставшийся живой корабль позднее погибает обычным способом, Space раскрывается от всех сохранившихся палуб. Если обычный Таран уничтожает живую палубу любого такого `manual_move_after_hit`-корабля — в том числе Маневрирующей двойки, Знаменитого Врезающегося корабля или Сливающегося корабля Ver.2, — владелец Тарана с рабочей Мачтой получает то же точное предупреждение **`[Мачта] Даёт по вёслам!`**, что и при выстреле.

После завершённого выстрела порядок фиксирован: выстрел и цепочки взрывов → немедленная проверка победы/абордажа → призывы в стабильном порядке появления, по одному шагу → на каждой новой клетке Grab, постоянный огонь, Freeze, столкновение с живой палубой (мёртвая проходима), яд/разведка → цепочки смертей → повторная проверка победы → ресет или смена хода. Регистрация обычного/ожидающего сумона и возврат Тарана тоже немедленно разрешают Grab, огонь, Freeze и столкновение, поэтому после них обязательно повторяются проверки победы и триггера абордажа. Penalty, Stun и невалидные действия призывы не двигают.

После столкновения Проклятой лодки её владелец получает обязательный интерактив на вражеском поле: лодка выделена, все соседние клетки внутри поля, соответствующие допустимым направлениям, ярко-зелёные и кликабельные, а остальной интерфейс серый и заблокирован. Отдельных кнопок направления нет. Если столкновение одновременно запустило Финальный абордаж, сначала единственный владелец абордажа размещает все обязательные единицы и только затем выбирается новый курс лодки; это исключает взаимную блокировку двух обязательных стадий. Если ход принадлежит боту, его pump соблюдает тот же приоритет.

### 3.5. Просветка клеток

| Действие | Просветка |
|----------|-----------|
| Промах | Просвечивается клетка промаха |
| Попадание в палубу | Просвечивается клетка попадания |
| Убийство/захват корабля | Просвечиваются все клетки в Space вокруг корабля |
| Гибель CAPTURE-корабля на поле исходного владельца | Захвативший игрок получает просветку всех клеток в Space вокруг изначально вражеского корабля |
| Разведчик | Отложенная поклеточная просветка только координат, непосредственно попавших в его радиус (информация выдаётся после гибели/столкновения/выхода; пустота получает «Промах», каждая попавшая палуба — отдельную анонимную белую метку; весь корабль автоматически не раскрывается) |
| Абордажный корабль | Накапливает координаты в своём Space на клетке появления и каждом шаге, но передаёт их только при обычной гибели, в том числе от завершающего столкновения; достижение края и ожидание разворота информацию не выдают |
| Сумон погиб от Freeze | Просвечивается точная клетка гибели: пустота получает «Промах», целая палуба — анонимную белую метку корабля; отложенные данные Разведчика или абордажного корабля при этом не передаются |
| Разведчик или абордажный корабль убит прямым выстрелом Горючки / Злой горючки | Накопленная отложенная информация удаляется и не передаётся |

Повторная просветка уже раскрытой клетки **не увеличивает** счётчик. Максимум = 100. Очки просветки получает только владелец выстрела/Разведчика/Тарана, который раскрыл клетку; владелец атакованной физической доски за чужую просветку очков не получает.

**Просветка — точный поклеточный снимок на момент наблюдения, а не постоянное слежение.** Белая, красная или жёлтая отметка конкретной палубы появляется только после её реального наблюдения — выстрела, разведки или раскрытия Space. Сам факт уже раскрытой координаты означает лишь, что игрок когда-то видел содержимое этой клетки: если тогда там была вода, скрыто переместившаяся на неё палуба не становится видимой. Если Маневрирующая двойка, Знаменитый Врезающийся корабль, Тройка из лёгкого дерева или собранный корабль передвинулись, повторная разведка их новой клетки показывает находящуюся там конкретную палубу белой или красной; прежняя отметка этой же палубы удаляется, а освобождённая раскрытая клетка становится водой с «Промахом». Остальные ещё не разведанные изменения остаются скрыты. При окончательной гибели обе проекции синхронизируются с текущими сохранившимися палубами, а освобождённые клетки становятся раскрытой водой с «Промахом»; последняя розовая отметка конкретной Тройки из лёгкого дерева удаляется. При гибели любого корабля раскрывается весь его Space, включая клетки соседних целых или уничтоженных палуб: целые показываются белыми, уничтоженные — красными, без раскрытия имени/точной прочности. Если в Space находится переместившаяся уничтоженная палуба Знаменитого Врезающегося корабля, её новая клетка становится красной, а прежняя отметка той же палубы исчезает.

## 4. Статусы и взаимодействия

### Определения статусов

| Статус | Эффект |
|--------|--------|
| **Burn** | Весь корабль мгновенно сгорает (все палубы уничтожены). Попадание горючкой даже в уже повреждённую палубу сжигает весь корабль. |
| **Burn resist** | Иммунитет к burn. Любое прямое огненное попадание или клетка взрыва по живой палубе окрашивается чёрным у обоих игроков и получает одновременно статусы «Корабль устоял против огня» и «Поцарапано». Переносная механика (не привязана к одному кораблю). |
| **Freeze** | Выключает корабль/сумона из игры (эквивалент смерти). При гибели сумона просвечивается его точная клетка по обычным правилам пустоты/анонимного корабля. Срабатывает даже при столкновении — урон не наносится. Разведчик и абордажный корабль при Freeze **не** передают накопленную информацию. |
| **Devastated** | Аналог freeze, но с чёрной окраской всех клеток у обоих игроков. Выключает корабль из игры. Вражеская Пиратская лодка может захватить такой корпус независимо от исходного числа палуб; собственная Пиратская лодка может вместо выпуска полностью восстановить его. |
| **Capture** | Обязательный дебафф исходного владельца. Его нетронутые палубы фиолетовые у обоих игроков; повреждение/уничтожение имеет визуальный приоритет. Пока корабль жив, владелец может целиться только в его палубы на своей доске, но выбирает любой иначе доступный снаряд; выбранный боезапас и его обычный эффект расходуются штатно, а выстрел завершает ход. Повторная Пиратская лодка статус не снимает. Корабль не даёт пассивки, регионы или значение для победы, но его живая Баллиста доступна захватившему игроку до уничтожения исходным владельцем. Единственное исключение из отключения пассивок: захваченная Горючая баржа взрывается от первого валидного попадания исходного владельца. |
| **Destroy** | Уничтожает палубу и выключает модуль на ней. Особый цвет закраски. |
| **Stun** | Пропуск хода. Срабатывает на следующий или через один выстрел. Исчезает после срабатывания или истечения времени. |
| **Penalty** | Пропуск следующего хода. Без срока давности, исчезает после срабатывания. |
| **Электрический заряд** | Постоянная метка клетки. Она появляется только при попадании Нептуна в обычную или уничтоженную палубу корабля, живого сумона/лодку либо живую или уничтоженную палубу абордажного корабля. Промах по воде и отдельный иммунитет к Нептуну метку не создают. Метка остаётся на физической клетке независимо от дальнейшего движения или гибели цели. |

### Матрица взаимодействий

| Источник | Цель | Результат |
|----------|------|-----------|
| Burn | Корабль с burn resist | Нет эффекта |
| Burn | Пираты / Проклятый пират | Корабль сгорает, сумон **не** выпускается |
| Freeze (Драккар) | Любой сумон в Space | Сумон уничтожен, урон не нанесён |

Постоянного огня на клетках не остаётся. |
| Три выстрела одного Нептуна создали три разные метки на одном физическом поле | Клетки, чья площадь не менее чем на 50% находится внутри треугольника центров меток | Корабли, сумоны/лодки и абордажные корабли на этих клетках немедленно получают результат Burn как от Горючки; `Burn_resist` защищает корабль. Бирюзовый контур и история Burn остаются видимыми, но клетки не превращаются в постоянную ловушку Греческого огня. |

Начальный четырёхпалубный корпус называется **«Русская Матрешка»**. При его полном уничтожении владелец обязан поставить свежий трёхпалубный **«Мать Матрешка»** прямо на трёх из четырёх клеток уничтоженного корпуса. Сервер предлагает ровно два варианта: отбросить первую либо последнюю палубу исходной прямой последовательности; ориентация сохраняется. Оба варианта цветом показывают все входящие клетки, а их разные крайние клетки помечены `I` и `II` и принимают выбор.

Полное уничтожение «Мать Матрешка» тем же способом создаёт двухпалубную **«Матрена»** на двух из трёх клеток; полное уничтожение «Матрена» создаёт однопалубную **«Матренушка»** на одной из двух клеток. «Матренушка» больше не раскрывается. Новый корпус всегда целый, выбранные клетки становятся его текущими белыми палубами, а невыбранная клетка сохраняет красный труп предыдущей стадии. Противник при каждом раскрытии получает точную фразу **«Матрешка вскрылась! Стреляй заново!»**. Варианты клеток, имя следующей стадии и геометрия доступны только владельцу; противник видит лишь факт обязательного выбора. Незавершённое раскрытие не позволяет объявить уничтожение флота или начать Финальный абордаж.

Раскрытие является пассивной реакцией именно на окончательное уничтожение корпуса. Оно не срабатывает, если пассивы выключены статусом CAPTURE, если корпус лишь временно обнулён статусом `Devastated`, или если палубу/корабль структурно удалил Знаменитый Врезающийся корабль по правилу «словно его не было». При уничтожении во время движения сумонов разрешение останавливается сразу после вызвавшего его шага (включая отдельное попадание яда) и после выбора продолжается со следующего ещё не обработанного шага без повторного урона. До возобновления разрешения свежая стадия последовательно проверяет горящие клетки, ауры вражеских абордажных Драккаров, физическое пересечение с сумоном и действующие ядовитые конусы; такая опасность может сразу уничтожить её и открыть следующую стадию.

## 7. Юниты — Сумоны

### Общие правила сумонов

- **4 обычных призыва за матч**. Счётчик не возвращается при гибели сумона. Бесплатные сумоны собственных кораблей (Пиратская/Проклятая лодка и абордажные корабли) этот лимит не занимают; **Брандер также вне лимита** и имеет собственный предел 1 за матч (ТЗ #10).
- **Доступность по регионам флота** (ТЗ #11/#12): Таран — только при кораблях региона Запад, Разведчик — Восток, Пиратская лодка — Юг. CAPTURE-корабль не даёт регион или пассивку. Недоступные типы скрыты из списка призыва; возврат уже созданного сумона не требует региона заново.
- **Условие призыва:** 5 просвеченных клеток на вражеской карте за каждого сумона (2-й сумон = 10, 3-й = 15, 4-й = 20).
- **Прочность** = 1 (ваншот).
- **Призыв не тратит ход.** Можно призвать в любой момент, даже посреди вражеского хода — **и даже во время вражеского выстрела**, пока он ещё разрешается или анимируется. Если сумон доступен, постановка обязана быть доступна: выпуск никогда не блокируется ни владением ходом, ни reset-перезарядкой стреляющего.
- Максимум **1 сумон за 2 завершённых глобальных выстрела**. Обязательная высадка и последующие действия зафиксированного владельца `final_rush`/`BoardingPlayerId` обходят эту каденцию; второй игрок во время абордажа продолжает соблюдать её. Бесплатные ожидающие призывы сохраняют свои обычные исключения.
- Сумон появляется на любой клетке **1-й строки** вражеского поля. Перед подтверждением расстановки игрок выбирает глобальный режим **Суммоны** или **Лодки**; дефолт — Лодки.
- В режиме **Суммоны** движение начинается после следующего выстрела (призвал → стоит → выстрел → передвинулся).
- В режиме **Лодки** новая или возвращённая единица сначала призрачна на протяжении одного следующего союзного или вражеского выстрела. В это окно она не двигается, не сталкивается, не замораживается Драккаром и не погибает от ядовитого конуса. После разрешения выстрела она материализуется на текущей клетке, немедленно проходит обычные проверки огня/Freeze/столкновения/яда, а двигаться начинает только после следующего выстрела. Прямой выстрел, включая Дробь или огненный снаряд, может уничтожить призрачную лодку.
- Двигается сверху вниз, проходя за каждый выстрел столько клеток, сколько имеет скорости.
- **Проходимость** (ТЗ #15/#16): все сумоны проходят сквозь клетки с палубами 0 HP; столкновение вызывает только живая палуба. Брандер не проходит сквозь живые палубы — разбивается без детонации.
- **След:** клетки пути сумона, включая клетку появления и клетку столкновения, навсегда хранят тип и идентичность каждого посетившего их сумона. Следы не вытесняют друг друга: обычные значения перечисляются как «След: Таран», «След: Разведчик» и т. д., а все конвертированные Close объединяются под доской в одну легенду **«След: Абордажный корабль»** без имени источника. Внутренний маркер, tooltip клетки, активный призыв и смерть по-прежнему сохраняют конкретный исходный корабль, например «Погиб: Абордажный корабль (Драккар)». На своей карте виден след вражеских суммонов, на карте противника — след своих.
- **Достигнув края карты:** любой **Таран**, включая абордажный корабль, можно пустить обратно через соседнюю клетку противоположного края. Это перенаправление конкретной существующей единицы: новый лимит/порог разведки не проверяется, а Мачта сообщает фактическую клетку повторного входа. Пока один или несколько Таранов ждут возврата, их отдельные иконки — единственные доступные действия призыва; выбрать нужно точную единицу. Если во время обязательной высадки ни у одного ожидающего Тарана нет легальной соседней клетки возврата, недоступный остаток обязательных единиц отбрасывается и прерванное разрешение продолжается; сам Таран остаётся живым и сохраняет приоритет для будущего возврата после движения на поле. Все остальные типы после выхода за границу удаляются.

### Штраф при убийстве сумона

| Ситуация | Результат |
|----------|-----------|
| Убийство обычного сумона на **1–3 строках** | Враг получает **Penalty** (штраф) |
| Полное уничтожение абордажного корабля на любой строке | Ход прерван; **Penalty нет**, а сама гибель корпуса не даёт ресет, включая Дробь и огонь. Уничтоженная той же Дробью палуба обычного корабля может дать независимый обычный ресет |
| Стрелок уничтожил палубу или весь **свой** абордажный корабль на вражеском поле | Действие безусловно завершает ход: ресета нет даже от частичной палубы и даже при другой серийной пассивке |
| Убийство при **появлении** (до движения) | Ход прерван, штрафа **нет** |
| Убийство **призрачной лодки** выстрелом | Ход прерван, штрафа **нет** независимо от строки |
| Убийство на **4+ строках** | Ход прерван, штрафа **нет** |

Владелец вручную ставит лодку в одну из колонок, занятых кораблём перед конверсией; уничтожение до абордажа ничего не создаёт |
| Второй боезапас | 6 монет | Во время абордажа рабочему Тетракамнемёту этого живого Triple выдают **2 Белых камня независимо от выбранного при расстановке типа**, вместо обычного +1 Белого камня за настройку на Дробь. Если исходным типом была Дробь, её прежний боезапас сохраняется, а бонус всё равно появляется как Белый камень. Бонус увеличивает текущий и максимальный восстанавливаемый боезапас Белого камня |
| Броня | 4 монеты / палуба | +4 к прочности на палубу 1 или 3. Палуба 2 с Тетракамнемётом уже имеет встроенную броню +2 HP; её затемнённая опция неинтерактивна и повторно не покупается |

> Полная платная прокачка Трёшки = 16 монет (Экипаж 2 + Боезапас 6 + Броня 4×2 = 8). Встроенная броня центральной палубы бесплатна.

## 9. Финальный абордаж

### Триггер

Первая смена состояния, после которой хотя бы у одного игрока не остаётся живых кораблей класса Mid, запускает **один глобальный** Финальный абордаж. Сервер в этот момент навсегда фиксирует единственного владельца абордажа: обычно это противник текущего стрелка, чья Mid-линия только что исчезла; при редком одновременном исходе используется тот же детерминированный приоритет. Второй игрок не получает собственную конверсию и обязательную высадку, даже если позже тоже теряет все Mid. Проверка выполняется после каждого разрешения, способного сразу уничтожить палубу, включая столкновение сумона при его выпуске или возврате. Переход идемпотентен: конверсия, Экипаж и бонусные снаряды выдаются ровно один раз.

Иконка «Абордаж» в обоих клиентских ракурсах стоит только рядом с ником этого зафиксированного владельца абордажа — игрока, потерявшего Mid, — независимо от того, сверху или снизу показана его доска.

### Механика

1. В начале перехода сервер один раз формирует обязательный снимок **только для владельца абордажа**: все его уже ожидающие сумоны; каждый ещё не израсходованный обычный слот, если в купленном флоте есть Запад, Восток или Юг; купленный, но не выпущенный Брандер; отдельная Пиратская лодка от каждого живого корабля с «Экипажем»; а также подходящие Close-корабли. Обычные Таран/Разведчик/Пиратская лодка и Брандер остаются сумонами, а не превращаются в абордажные корабли. Уже размещённые живые сумоны обеих сторон продолжают движение на поле.
2. Владелец абордажа превращает каждый свой живой незахваченный **Close** / **Close (melee)** с живой палубой №1 (носом) в обязательный абордажный корабль. Корабль с уничтоженным носом не конвертируется. Второй игрок всегда сохраняет Close на своей доске и никогда не конвертирует их в этом матче. Конверсия переносит поклеточно текущий/максимальный HP, модули, их разрушение, форму корпуса, способности и статусы-механики: Ballista immunity остаётся иммунитетом, Burn resist — устойчивостью, а не одно-HP прокси. Конвертированный корабль немедленно освобождает свои исходные клетки и исчезает из `PlacedShips`: на своей доске, в активных пассивках и в подсчёте живого флота второй копии нет. Освобождение **не** создаёт искусственный «Промах», не просвечивает неизвестную клетку и не стирает уже существовавший реальный статус/снимок ни у одного зрителя; клетка без прежнего наблюдения остаётся непросвеченной. До обязательной расстановки корабль существует как ожидающий снимок, после неё — только как реальный многопалубный корпус на вражеском поле. Если все его палубы погибают от Grab, Freeze, огня, яда, столкновения или выстрелов, исходный корабль также окончательно погибает.
3. Для владельца абордажа фиксируется исходная вместимость входа: число клеток 1-й строки вражеского поля без живого сумона, максимум **10**. Каждая обязательная постановка расходует одну единицу этой вместимости, даже если новый сумон тут же погиб. Владелец сам выбирает, какие единицы поставить первыми; когда исходная вместимость исчерпана либо больше нет ни одного легального обязательного размещения, все оставшиеся обязательные сумоны и абордажные корабли сразу исчезают, их обычные/брандерные лимиты считаются израсходованными, а отброшенные Close окончательно погибают.
4. Все элементы обязательного снимка необходимо разрешить до продолжения прерванного выстрела. Пока остаётся легальная обязательная единица, действует глобальный барьер: владелец абордажа может выполнять только обязательную постановку или восстановление собственного Devastated-корабля обязательной Пиратской лодкой; стрелять, маневрировать, выпускать необязательные призывы, выбирать новый курс Проклятой лодки или передавать ход нельзя. После последней постановки приостановленное разрешение возобновляется и, если лодка всё ещё ждёт, курс выбирается следующим. Бот соблюдает тот же приоритет.
5. Абордажные корабли передвигаются как единый многопалубный корпус — сверху вниз, проходя за каждый выстрел столько клеток, сколько имеют скорости. Баллиста повреждает физическую палубу обычным уроном и уничтожает корпус только после гибели последней палубы; `ballista_immune` полностью отклоняет Баллисту. Вход любой живой палубы корпуса в активную клетку Grab немедленно убивает весь абордажный корабль без бесплатной копии. Единственное исключение — корпус, чей стабильный `SourceShipId` разрешается в сохранённом флоте ровно в исходный `DefinitionId == "drakkar"`; унаследованная `freeze_nearby` исключения не даёт. Такой Драккар проходит Grab. Он всегда ставится сразу вертикально тремя палубами вниз: при носе A1 он занимает A1–A3 уже в момент появления и дальше сдвигает все три клетки вместе. Его аура от каждой живой палубы замораживает и выводит из игры только вражеские корабли физической доски; свои абордажные корабли и сумоны владельца иммунны к этой ауре.
6. Их разведка в радиусе Space полностью отложена: координаты копятся на появлении и каждом шаге, а показываются только после обычной гибели, в том числе от завершающего столкновения. Достижение края и ожидание разворота информацию не выдают. Прямое убийство Горючкой / Злой горючкой и Freeze стирают накопленную информацию.
7. После достижения края каждый абордажный корабль ждёт ручного разворота как Таран и возвращается через соседнюю клетку. Пока такой Таран ждёт, другие призывы заблокированы.
8. Если после размещения нет легального выстрела, «Двигать призывы / Пас» двигает их один раз и завершает ход.
9. Выстрел по любому абордажному корпусу, принадлежащему самому стрелку и находящемуся на вражеском поле, всегда завершает действие после разрешения: уничтожение отдельной палубы или всего своего корпуса не даёт ресета и не может быть превращено в дополнительный выстрел другой серийной пассивкой. Полное уничтожение **вражеского** абордажного корабля на своей доске тоже не выдаёт Penalty за строки 1–3 и само по себе не даёт ресета. Если та же Дробь одновременно уничтожила палубу обычного вражеского корабля, только эта отдельная обычная палуба может сохранить ход.

### Урон при таране

| Цель | Результат |
|------|-----------|
| 1–2-палубный корабль, обычный абордажный корпус | Накладывает **Devastated**, плывёт дальше |
| 3–4-палубный корабль, обычный абордажный корпус | Урон от тарана = 4, абордажный корабль **погибает** |
| Корабль любого размера, абордажный Проклятый пират | Накладывает **Devastated**, остаётся жив и ждёт обязательного выбора нового курса; более специальное правило цели имеет приоритет |

### Дополнительно

- Каждый ещё не использованный обычный призыв из регионов купленного флота и купленный неиспользованный Брандер входят в обязательный снимок; порог разведки и обычная перезарядка при этой постановке не применяются. После обязательного барьера только зафиксированный владелец `final_rush`/`BoardingPlayerId` сохраняет абордажное исключение из обычной двухвыстрельной перезарядки. Второй игрок выпускает необязательные сумоны/лодки и возвращает ожидающие единицы с той же каденцией, что до абордажа: не чаще одного раза за два завершённых глобальных выстрела; прежние исключения бесплатных ожидающих призывов сохраняются.
- При постановке абордажного корабля защитник с рабочей Мачтой получает отдельное точное сообщение **`[Мачта] Корабль идёт НА АБОРДАЖ! (<клетка>)`**. Сообщение обычного Тарана **`[Мачта] Это таран!`** для абордажного корпуса не используется.
- Каждый живой Triple с «Экипажем» даёт собственную обязательную видимую Пиратскую лодку. Игрок вручную выбирает одну из колонок, занятых этим Triple при его расстановке; горизонтальный Triple разрешает до трёх соответствующих колонок.
- Это же правило Экипажа применяется к любому будущему носителю апгрейда и к Знаменитому захватывающему кораблю: только выживший носитель владельца абордажа создаёт лодку, а смерть до перехода не создаёт посмертный призыв.
- Абордажный Проклятый пират сохраняет способность Проклятой лодки: после Devastated-столкновения остаётся жив и блокирует остальные действия, пока владелец не выберет соседнюю клетку и новый курс вверх/вправо/влево/вниз.
- Каждый живой рабочий Тетракамнемёт, настроенный перед боем на Дробь, при начале абордажа получает +1 **Белый камень**; исходная Дробь не превращается и не исчезает. Если живой Triple купил «Второй боезапас», его рабочий Тетракамнемёт вместо этого получает +2 Белых камня независимо от исходной настройки. Горючка либо заменившая её Злая горючка получает +1. Каждая прибавка увеличивает и текущий боезапас, и сохранённый максимум своего типа, поэтому полное восстановление Пиратской лодкой возвращает также абордажные снаряды.
- Захваченный вражеский Close даёт захватившему игроку свою живую Баллисту, пока исходный владелец не уничтожит CAPTURE-корабль.

## 10. Условия победы и поражения

### Победа

1. Уничтожить **все** учитываемые вражеские корабли (не считая обычных сумонов и кораблей под CAPTURE). Ожидающий или живой абордажный корабль считается продолжением своего исходного Close и не позволяет объявить уничтожение флота до собственной гибели. Уничтоженная стадия Русской Матрешки с ожидающим обязательным раскрытием тоже считается продолжающимся корпусом; проверка победы выполняется только после постановки следующей стадии.
2. Оставить противника без живого/работающего оружия и без живого или ожидающего Тарана, Брандера либо Проклятой лодки, способных нанести урон. Боезапас не сравнивается с числом оставшихся палуб.

### Поражение

1. Все учитываемые корабли уничтожены.
2. Не осталось ни одного живого/работающего оружия и ни одного живого/ожидающего юнита, способного нанести урон.

### Особые случаи

- **Иссушитель:** если абордаж начинается от любой стороны и живой незахваченный Иссушитель есть только у одного игрока, матч завершается победой его владельца **до** фазы расстановки. Если живы оба Иссушителя, абордаж идёт по обычным правилам и остальные их пассивки продолжают работать; как только один Иссушитель уничтожен, второй немедленно приносит владельцу победу.
- **Capture:** корабль временно не имеет значения для победы ни одной стороны; исходный владелец обязан уничтожить его на своей доске выбранным иначе легальным снарядом, и каждый такой выстрел завершает ход.

## 11. Кто ходит первым

### Мини-игра (основной режим)

Приоритет по убыванию:

1. У кого больше **непотраченных монет**.
2. У кого **меньше** платно изменённых юнитов: платная замена или хотя бы один платный апгрейд, включая бесплатные Трёшку и флагман своей армии.
3. У кого **меньше** домашних юнитов.
4. Стабильный для ID матча seeded random.

### Настоящая игра (будущее)

Тот, кто находится на своей половине моря.

## 12. Пропуски хода

### Stun (оглушение)

Если на игрока наложен stun, он пропустит ход, если этот ход начнётся на **следующий** или **через один выстрел** после получения стана. Эффект пропадает после срабатывания или истечения.

**Примеры:**
1. Станящий выстрел попал в палубу → ресет → промах → **враг пропускает** (через 1 выстрел).
2. Станящий выстрел промахнулся → ход врага → **сразу отменяется**, ход возвращается (на следующий выстрел).
3. Станящий выстрел попал → ресет → **снова** попал → стан уже рассеялся.

### Penalty (штраф)

Игрок пропустит **следующий ход**, независимо от того когда он наступит — хоть через сто выстрелов. Эффект пропадает после срабатывания.

Пропуск проверяется перед любым способом стрельбы, включая выстрел по собственной карте; смена цели не позволяет обойти Penalty или Stun.

Технически stun и penalty — право на бесплатный промах для врага, не сбивающий серию атак/ресетов.

## 13.1. Версии бота

При создании матча игрок сначала выбирает противника: **Игрок** открывает второе место в лобби, **Бот** закрывает его и показывает выбор V1/V2/V3. Выбранная версия хранится сервером в самом матче и отображается в списке игр и внутри лобби; присоединиться вместо явно выбранного бота нельзя.

- **V1 — классический.** Сохранённый для совместимости исходный бот: случайно собирает и расставляет допустимый флот, затем использует прежние локальные эвристики.
- **V2 — тактический.** Использует только Империю, строит разные законные флоты из нескольких архетипов и применяет классическую схему `поиск → добивание`: плотность возможных прямых кораблей, приоритет поцарапанных/раскрытых палуб, разумное расходование оружия, сумонов, манёвров и Пиратского восстановления.
- **V3 — эксперт.** Наследует все допустимые действия V2, но оценивает множество вариантов флота и расстановки, цену инициативы, синергии регионов и оружия, опасность собственных взрывов, вероятное расположение оставшегося флота противника и ценность каждого доступного действия. Из нескольких лучших вариантов выбирается взвешенный случайный, поэтому эксперт не повторяет одну сборку, расстановку или последовательность ходов.

V2/V3 всегда получают полный доступ к **собственному** полю и отдельную проекцию вражеского поля, эквивалентную человеческому туману войны. В неё входят только раскрытие/попадание/промах, поцарапанность и уничтожение, постоянный огонь, публичные метки уклонения и огнестойкости, публичные Freeze/Devastated/Capture, видимые сумоны и разрешённые Мачтой имена потопленных кораблей. Ссылки на вражеские `Board`, `Ship` и `Deck`, скрытые HP, модули, ориентация и новая позиция после скрытого манёвра в тактическую политику не передаются. Увиденное при живой Мачте можно запомнить так же, как это сделал бы игрок. Исчезновение ранее достоверной палубы и розовая метка уклонения обновляют только связанные гипотезы движения; одна маневрировавшая Тройка не превращает всё уже разведанное море обратно в неизвестное.

Экспертная карта вероятностей строится не по простой шахматной сетке, потому что в игре есть броня, диагональные/разреженные формы, сборка, Матрешка и скрытые перемещения. V3 перебирает разрешённые каталогом геометрии для известной фракции, оставшиеся слоты шаблона 4×1/3×2/2×3/1×4, известные по Мачте потери, бюджет и максимум трёх регионов. Гипотезы, противоречащие разведанной воде, потопленным корпусам, дальностным зонам и публичным следам, исключаются; попадания переводят модель в режим добивания, а локально достижимые позиции маневрировавшего корпуса сохраняются как альтернативы. Если скрытый ручной манёвр мог привести корпус в уже простреленную воду, после исчерпания обычных целей бот выполняет конечный повторный поиск: сначала по коротким осевым направлениям от устаревшего свидетельства и без повторения уже перепроверенных клеток до появления нового публичного следа движения. Заслуженный собирающийся корабль моделируется как раздельные компоненты до публичных свидетельств сборки, стадии Матрешки — как текущий возможный размер корпуса.

Сборка и бой V3 используют следующие правила:

- при выборе флота часть планов тратит почти весь бюджет, а часть сознательно оставляет монеты ради первого хода; архетипы артиллерии, абордажа, контроля, уклонения, разведки и сбалансированного флота имеют разные веса. V2/V3 могут редко выбрать Иссушителя как законный дорогой план, но не фиксируются на нём;
- расстановка ищет десятки законных полных планов, разводит взрывоопасные и дорогие корабли, не направляет собственный ядовитый конус в союзников, смешивает края/центры и ориентации, а Горючую баржу не прячет автоматически в зоне, из которой её огонь теряет дальние цели;
- тип снаряда и конкретный живой источник выбираются только при наличии достижимой ценной цели, после чего карта цели учитывает дальность именно этого источника. Горючка не тратится повторно в публичную огнестойкость, Белый камень предпочитает поцарапанные бронированные цели и абордажные корпуса (и разрушает модуль, если он действительно окажется на палубе, не раскрывая его заранее), Дробь выбирает наиболее плотный квадрат 2×2, Злая горючка использует известную уничтоженную палубу, а Ballista не повторяет салатовую клетку уклонения;
- при защите от Брандера бот до выстрела считает собственные уязвимые корабли и сумоны в радиусе 1 и не подрывает его автоматически себе во вред. Многопалубный абордажный корпус атакуется по реально живой видимой палубе; иммунный к Баллисте корпус получает подходящий Белый камень или огонь;
- Таран, Разведчик, Пиратская лодка, Брандер, Проклятая лодка и конвертированные абордажные корпуса ранжируются по угрозе, разведке, вероятной линии столкновения, публичным статусам и оставшейся вместимости. Сервер передаёт политике только авторитетно легальные линии полного корпуса, поэтому обязательный абордаж не может зависнуть на красивой, но физически невозможной клетке;
- V3 маневрирует в уже проверенные противником клетки, выбирает курс Проклятой лодки по карте вероятностей и расходует Пиратскую лодку на наиболее ценный Devastated-корпус. После разрешённого выстрела человека, который сохраняет ход за тем же человеком, бот получает ровно одно окно реакции: Злой Греческий огонь доступен только при реальной reset-паузе, а сумон или восстановление — также при продолжении без таймера.

Случайность выбирает архетип, темповый план и снаряжение, даёт ограниченное исследование при построении флота/расстановки и разрешает близкие по оценке варианты в шортлистах. Это обеспечивает разнообразие и не даёт человеку выучить один шаблон; все кандидаты по-прежнему проходят серверную проверку правил, а случайность не предоставляет боту скрытую информацию.

### Список активок в UI

- Баллиста — одна общая базовая кнопка независимо от числа кораблей
- Белый камень (Тетракамнемёт)
- Дробь (Тетракамнемёт)
- Горючка
- Злая горючка
- Греческий огонь (Котельная)
- Злой Греческий огонь (Котельная)
- Сумон: Пиратская лодка
- Сумон: Таран
- Сумон: Разведчик
- Сумон: Брандер
- Сумон: Проклятая лодка

Сервер присылает одну общую Баллисту и доступные специальные действия с ID исходного корабля, палубой/модулем, текущим и максимальным боезапасом, разрешённым типом снаряда, списком источников и остатком Aim в **разведанных клетках**. Уничтоженный корабль, палуба или модуль немедленно убирает соответствующий источник. Вне Финального абордажа источник анимации Баллисты циклически выбирается только среди живых палуб кораблей **Mid**. Во время абордажа владелец абордажа стреляет визуально из живых **Close** (не Close melee), фактически размещённых как абордажные корабли на вражеской доске; вторая сторона продолжает стрелять визуально из Mid. Уничтоженные источники пропускаются. В режиме камнемётов v1 экземпляры выбираются отдельно; в v2 сервер объединяет их в одну кнопку на тип снаряда, показывает общий остаток/максимум и перечисляет живые корабли-источники снизу. Несколько кораблей одного типа нумеруются в пределах флота (`Single 1`, `Single 2`, `Triple 1`…), чтобы источники оружия, статусы и логи оставались однозначными. Когда хотя бы один Тетракамнемёт готов, весь экран получает заметное белое свечение. После успешного выстрела Горючкой / Злой горючкой выбор сразу возвращается на Баллисту, если она доступна; другие конечные специальные боезапасы сохраняют обычный автоматический возврат после исчерпания.

На фазе расстановки уже поставленный корабль можно перетащить, зажав ЛКМ на любой его палубе; захваченная палуба остаётся под курсором. Первая палуба помечается как нос, а на палубах отображаются символы Баллисты, Тетракамнемёта, Мачты, Котельной, Горючки и усиленной брони. Те же символы особых палуб и нос показываются владельцу на своей доске во время боя. Прямой корабль имеет четыре направления носа, диагональный флагман — четыре диагональных направления; Space строится от реальных координат всех сохранившихся палуб. Декларативный реестр зон строит предпросмотр по ability-полям корабля: аура заморозки Драккара, ядовитые конусы Алхи-баржи/Алхи-айсберга и радиус взрыва Горючей баржи, Быстроразогревающегося корабля либо Разогревающегося корабля Ver.2 видны до подтверждения. Здесь же доступны глобальные переключатели **Камнемёт v1/v2** (дефолт v2) и **Суммоны/Лодки** (дефолт Лодки), а для каждого Тетракамнемёта — Белый камень/Дробь (дефолт Дробь). Поэтому полностью расставленный флот можно подтвердить без ручного изменения любого переключателя. Пока соперник не подтвердил свою расстановку, готовый игрок может отменить подтверждение и продолжить правки. В карточках выбора дальность **Close** всегда отображается дословно как `Close` и не переводится браузером в «Закрыть».

В каталоге Альянса Обычный Четырехпалубник заполняет четырёхпалубный слот по умолчанию; Знаменитый диагональный корабль и Русская Матрешка показываются как альтернативы по 10 монет. Обе версии разогревающегося и обе версии Сливающегося корабля отображаются как отдельные платные определения со своими точными названиями и свойствами. Во время обязательного раскрытия Матрешки собственная доска приглушается: два серверных варианта корпуса имеют разные полупрозрачные цвета по всей длине, а уникальные крайние клетки ярко помечены `I`/`II` и кликабельны. Сопернику координаты и цвета вариантов не передаются; его интерфейс глобально приглушён и заблокирован до завершения выбора. Клавиатурная стрельба и все прочие кнопки владельца также заблокированы, кроме выбора варианта.

Панель призывов находится сразу под оружием. Нажатие на доступную иконку обычного призыва сразу включает выбор клетки, без промежуточной кнопки; ожидающие и абордажные корабли показаны там же отдельными иконками. Активная иконка абордажного корабля подписана именем источника (`Single 1`, `Драккар`), а не «Таран». Если Таран ждёт разворота, все остальные иконки призыва неактивны и игрок выбирает точную ожидающую единицу. Появление нового призыва сопровождается вспышкой на клетке и звуком `pts combo 1`.

Статусы клетки передаются явно. Для CAPTURE нетронутая палуба фиолетовая у обоих игроков, но поцарапанная/уничтоженная/сожжённая окраска имеет приоритет; когда на союзном поле есть живой CAPTURE-корабль, остальной экран становится серым и приглушённым, а все его палубы получают очень мягкое ненавязчивое свечение. Devastated всегда остаётся чёрным у обоих. Огнеупорная палуба после огня/взрыва тоже чёрная, но tooltip различает её двумя статусами «Корабль устоял против огня» и «Поцарапано». Уничтоженная отдельная палуба сохраняет обычную отметку пробития, а все клетки полностью потопленного корабля получают отдельную тёмную перечёркнутую отметку. Точное имя потопленного вражеского корабля показывается в tooltip только пока у смотрящего игрока есть хотя бы одна рабочая Мачта; после потери последней Мачты имя сразу скрывается. Строки 9–10 затемнены на обеих досках как зона дальней дистанции. Иконка живого сумона накладывается поверх состояния клетки и исчезает из активных статусов сразу после любой смерти; живая конвертированная единица подписана «Абордажный корабль (Single 1)», но в общей легенде все его следы сводятся к «След: Абордажный корабль», а tooltip клетки и смерть сохраняют конкретное имя исходного корабля. На клетке остаётся **отдельная типизированная иконка смерти каждого погибшего сумона**, включая несколько одинаковых типов. Смерть от Freeze Драккара запускает анимацию замерзания, а конкретная иконка этой смерти сохраняет снежинку; tooltip пишет «Заморожен», а не обычное «Погиб». Tooltip перечисляет совмещённые статусы, все типизированные следы и смерти. Scout-разведанная целая палуба белая и показывает только факт наличия корабля, без имени и точной прочности. Фактически целая палуба на текущей клетке имеет приоритет над старой отметкой промаха — в том числе после уклонения Тройки из лёгкого дерева и манёвров Маневрирующей двойки / Знаменитого Врезающегося корабля. Уклонение Тройки из лёгкого дерева помечает только её последнюю исходную клетку розовым. Между ником и числом разведанных клеток заголовок каждой боевой доски показывает «Империя» или «Альянс». Пока жив хотя бы один активный корабль с перегревом — Быстроразогревающийся, Разогревающийся Ver.2 либо сохранивший это свойство Уютный Совместный — верхняя панель его владельца отдельно показывает авторитетный личный счётчик «Перегрев N/20»; после гибели/выключения последнего такого корпуса индикатор исчезает.

Когда сервер публикует обязательный манёвр, сборку корабля или выбор курса Проклятой лодки, все действия кроме выбора конечной клетки заблокированы. Боевое поле и интерфейс становятся серыми, активный корабль/сумон выделяется, а каждая разрешённая конечная клетка ярко-зелёная и кликабельная. Глобальный барьер обязательного абордажа аналогично оставляет каждому игроку только его обязательные иконки и показывает оставшуюся исходную вместимость входа. При выборе Пиратской лодки собственные Devastated-корабли подсвечиваются светло-зелёным: клик по такому кораблю расходует лодку на полное восстановление, клик по вражеской 1-й строке сохраняет обычный выпуск.

При гибели сумона в ядовитом конусе его владелец с живой Мачтой получает тёмно-зелёную личную строку «Призванное существо погибло в ядовитом конусе!». Классический V1 не покупает Иссушителя; разнообразные имперские планы V2/V3 могут выбрать его на общих правилах. Все версии не ставят союзные палубы в собственные ядовитые конусы, добивают только живые палубы CAPTURE-корабля и после салатовой отметки уклонения больше не стреляют Баллистой в эту клетку.

Девять финальных bitmap-иконок из GDD используются без перерисовки: Белый камень, Дробь, Горючка, Пиратская лодка, Таран, Разведчик, Брандер, Проклятая лодка и Греческий огонь. Остальные служебные/статусные значки остаются векторными.

Пропущенный из-за Penalty/Stun ход не считается выстрелом в клиентской статистике и не запускает VFX выстрела. Само действие, которое только что выдало Penalty, передаёт отдельный структурированный флаг и сразу показывает крупную полноэкранную надпись «ШТРАФ!»; это не заменяет более позднюю карточку фактического пропуска хода. Сервер передаёт физическую целевую доску, тип снаряда и непрозрачный ID исходного корабля/палубы: владелец видит полёт стрелы, камня, дроби или огня от реального оружия до цели, а скрытый источник противника не раскрывается. Промах даёт всплеск воды, попадание — щепки, гибель корабля — погружение в тёмную пучину; эффекты не участвуют в расчёте. Полёт попавшего снаряда длится примерно **3,2 секунды**, во много раз дольше обычного полёта, а серверная перезарядка запускается до VFX и идёт одновременно с ним. Полоса перезарядки и имя перезаряжающегося игрока видны обеим сторонам для своих и вражеских reset-атак. Призрачная лодка полупрозрачна и пульсирует; её tooltip прямо сообщает окно материализации и отсутствие штрафа. Брандер воспроизводит взрыв только при реальной детонации; Freeze Драккара воспроизводит заморозку и оставляет снежинку на маркере смерти, а безвредное столкновение с живой палубой остаётся визуально и звуково тихим. Во время абордажа сервер отдельно разрешает кнопку «Двигать призывы / Пас», только когда выстрелов действительно нет.

## 15. Нерешённые вопросы

1. **Мачта:** полный список сообщений (указано "позже будут прописаны").
