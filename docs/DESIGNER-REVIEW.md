# Лист решений для гейм-дизайнера

> Аудит кода нашёл места, где код и описания расходятся, но **непонятно, что из этого баг, а что задумано**. Для каждой строки поставь вердикт в колонке «Вердикт»: замени ❓ на **БАГ** (чиним код) или **ОК** (задумано — обновим доки), при желании добавь комментарий. Технические детали каждого пункта — в `docs/AUDIT-FINDINGS.md` по ID. После заполнения Claude сгруппирует фиксы в батчи.
>
> Важно: **описания пассивок в characters.json Claude не редактирует** — они намеренно расплывчатые, это твой голос для игроков. Если по вердикту нужно поменять игровой текст — впиши новую формулировку в «Комментарий» (она будет вставлена дословно) или поменяй сам; Claude обновляет только технические доки.
>
> Однозначные string-баги чиним без обсуждения, если нет возражений: **C1** (Салдорум/Salldorum — мёртвый бот-ИИ), **m1** (Вампур_ — мёртвая пасхалка с чесноком), **m22** (Saitama/Сайтама — корона 👑 на топ-1 не показывается).
