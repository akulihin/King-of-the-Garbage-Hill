Шэн is an action redirect, not a forced-fight source. A successful dash works from either direction and replaces only the first non-self target already present in the **selected target's** queue; crossed players are untouched, no fight is appended, and a selected Block/Skip with no attack stays unchanged. A round-10-banned player (Тигр always; Dopa only after the top-1 Permaban trigger) cannot be selected through the ordinary action path, then Мадара/Naruto sanitation revalidates the changed queue. Directly targeting unknown_bug produces only the submitted ordinary attack and spends no charge; a projected dash/hold that would move unknown_bug is cancelled, and its own queue is never rewritten. The same dash is a one-round random-target override: it replaces Rick (when present) or one ordinary Спартанец mark, redirects Kira's L/Weedwick's hunter priority and any same-round Великий Комментатор reveal to the holder, and consolidates every currently banked Геральт contract onto the holder. Original random targets resume next round; copied Шэн uses the copy holder as the magnet (`Salldorum.cs` `ResolveShenDashes`/`ApplyShenPositionHolds`/`FindRandomTargetMagnet`/`IsRedirectedRandomTarget`/`TakeGeraltContractCount`; `Tigr.IsRoundTenBanned`).

Джон Сноу's **Еще один бастард** is another action redirect. Its two `🐺` marks (owner-only visibility — only the Джон Сноу player sees them, M133; the redirect itself runs server-side regardless) are the lowest current-Skill non-Jon players, using Сайтама's strongest-target formula in ascending order. If Jon submitted an attack against an enemy whose finalized queue contains one of those marks, the first such target is replaced with Jon; no extra fight is appended. Existing forced queues remain eligible even if that enemy submitted Block/Skip. Dead redirecting enemies, unknown_bug and any player in the shared round-10 ban are excluded; Вечное Цукуеми and the Kratos event suppress the redirect, and sealed-Madara/Naruto sanitation runs again afterward. A resolving qualifying defence gives Jon +1 one-fight Justice and +1 to every fight stat (`JonSnow.RefreshWeakestPlayers`/`RedirectBastardAttacks`/`ApplyDifficultyJustice`; CP `Неприметность`; `CheckIfReady.TickAsync`; `Tigr.IsRoundTenBanned`).

Кратос's **Клинки хаоса** are another queue-expansion source outside the table: the selected target remains, but unknown_bug is filtered from both incidental neighbour additions (`GameReactions.HandleAttack`).

The Гарем row applies only to the original Naruto, when its cooldown is 0 and the submitted Block is converted. For the next two turns after a use, the original's Block remains ordinary, so every forced-fight interaction follows the normal Block row instead. Теневые clones have no Block slot at any AI level and Skip only if no attack can be accepted (`Naruto.cs:40-41`, `Naruto.cs:192-200`; `BotsBehavior.cs:3464-3467`, `BotsBehavior.cs:4397-4401`, `BotsBehavior.cs:4554-4565`; `GameReactions.cs:913-936`; CP:3771-3784).

Гордон can spend **Просыпайтесь, мистер Фримен** once while alive to clear a current Skip and reopen an ordinary action; it does not itself inject a fight. The same button appears when Gordon is the active **Глаза Итачи** target: waking clears both of that carrier's target slots before collection, so this Цукуеми pays/copies nothing further and its charge is not refunded; Gordon nevertheless stays in that carrier's `CaughtPlayers` list, so the technique can never be applied to him again (once-per-enemy rule). The charge also appears mysteriously on round 9 only when Мадара's Вечное Цукуеми is already armed—not merely because an unsealed Мадара exists. Spending it reserves Gordon's sole real-action exception on round 10. Death and the Кратос event cannot be woken (`GordonFreeman.CanWake`/`Wake`/`CancelItachiEyes`; `Madara.IsEternalTsukuyomiActive`/`PrepareEternalTsukuyomiRound`).

Bot and auto-move action selection spends pending level-ups and then finalizes any resulting or pre-existing Skip through `BotsBehavior.CompleteForcedSkip` before choosing an action. The post-level-up gate is required for Darksci's round-9 Дизмораль (M32): it cannot become an ordinary bot attack, while the forced-fight sources above still work because they inject their targets later in the readiness/fight pipeline.

The round-10 bot march is an action-selection preference, not a fight injection. At every AI level a selectable `Монстр без имени` has roster-wide priority. Only when no Monster exists does a bot below selectable Eren attack him, including place 6; Dopa Macro then adds its required second distinct target (`BotsBehavior.TryForceRoundTenBossAttack`). Dead, forced-skipping, round-8/sealed Madara, a round-10-banned target and any other unable-to-act state remain authoritative. Eren can still block or activate an off-cooldown Attack Titan against those ordinary incoming fights.

Omni-man's hidden initialization rule is the final initial-position mover: if he would begin at place 1 after Homelander and Jon are finalized, he is swapped with the earliest available seat that is neither unknown_bug nor Jon (falling back to seat 2 only if necessary).
