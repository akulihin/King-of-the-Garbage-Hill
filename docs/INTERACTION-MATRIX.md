Шэн is an action redirect, not a forced-fight source. On a successful forward dash it replaces only the first non-self target already present in each crossed living player's queue; it never appends a fight, and a crossed Block/Skip with no attack stays unchanged. Dead players and the round-10-banned Тигр are ignored, then Мадара/Naruto sanitation revalidates the changed queues. Directly targeting unknown_bug produces only the submitted ordinary attack and spends no charge; a projected dash/hold that would move unknown_bug is cancelled, and its own queue is never rewritten. The same dash is a one-round random-target override: it replaces Rick (when present) or one ordinary Спартанец mark, redirects Kira's L/Weedwick's hunter priority and any same-round Великий Комментатор reveal to the holder, and consolidates every currently banked Геральт contract onto the holder. Original random targets resume next round; copied Шэн uses the copy holder as the magnet (`Salldorum.cs` `ResolveShenDashes`/`ApplyShenPositionHolds`/`FindRandomTargetMagnet`/`IsRedirectedRandomTarget`/`TakeGeraltContractCount`).

Кратос's **Клинки хаоса** are another queue-expansion source outside the table: the selected target remains, but unknown_bug is filtered from both incidental neighbour additions (`GameReactions.HandleAttack`).

The Гарем row applies only when its cooldown is 0 and the submitted Block is converted. For the next two turns after a use, that Block remains ordinary, so every forced-fight interaction follows the normal Block row instead (`Naruto.cs` `HaremCooldownTurns`/`ResolveHaremQueues`; CP:3771-3784).

Гордон can spend **Просыпайтесь, мистер Фримен** once while alive to clear a current Skip and reopen an ordinary action; it does not itself inject a fight. The same charge appears mysteriously on round 9 only when Мадара's Вечное Цукуеми is already armed—not merely because an unsealed Мадара exists. Spending it reserves Gordon's sole real-action exception on round 10. Death and the Кратос event cannot be woken (`GordonFreeman.CanWake`/`Wake`; `Madara.IsEternalTsukuyomiActive`/`PrepareEternalTsukuyomiRound`).

Bot and auto-move action selection spends pending level-ups and then finalizes any resulting or pre-existing Skip through `BotsBehavior.CompleteForcedSkip` before choosing an action. The post-level-up gate is required for Darksci's round-9 Дизмораль (M32): it cannot become an ordinary bot attack, while the forced-fight sources above still work because they inject their targets later in the readiness/fight pipeline.

Rumbling's round-10 bot march is an action-selection preference, not a fight injection. L0/L1 keep the historical scripted override: a bot at an opening place strictly between Eren and place 6 attacks Eren, with Dopa Macro adding its required second distinct target. L2/L3 are not told which masked row is Eren; they apply the same rule only after legal prediction/log/roster evidence makes that row a Rumbling candidate (`BotsBehavior.TryForceRumblingAttack`, `InferPublicRulePatterns`, `ApplyFairCharacterPreference`). Dead, forced-skipping, round-8/sealed Madara and any other bot that cannot act retain that state. Eren can still block or activate an off-cooldown Attack Titan against those ordinary incoming fights.
