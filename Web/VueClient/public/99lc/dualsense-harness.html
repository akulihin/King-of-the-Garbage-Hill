How to use this harness

  1. Serve the Vue public folder through HTTPS or localhost, connect the controller, and start Gamepad capture.
  2. Review a transport serializer captured from a physically verified device/transport outside this repository.
  3. Inject that serializer from DevTools with the hook below. Its filters and packet bytes remain only in this page's memory.
  4. Click Request & open verified HID. Merely opening this page or choosing a control scheme elsewhere never requests permission.
  5. Exercise each semantic event and analog gate. Inspect acknowledgement/error and timing entries.
  6. Neutralize or close, physically inspect both triggers, record the human confirmation, then export. Support marking additionally requires an acknowledged semantic output report.
window.install99LcVerifiedDualSenseHarnessTransport({
  transport: 'usb', // or 'bluetooth'
  filters: [{ vendorId: VERIFIED_VENDOR, productId: VERIFIED_PRODUCT }],
  supports: device => YOUR_VERIFIED_CHECK(device),
  serialize: semanticEvent => YOUR_VERIFIED_SERIALIZER(semanticEvent),
  neutral: () => YOUR_VERIFIED_NEUTRAL_SERIALIZER()
})

// serialize()/neutral() return:
// [{ reportId: NUMBER_FROM_VERIFIED_FIXTURE, data: Uint8Array }]
// This harness never prints or exports reportId values or packet bytes.

Privacy boundary: no localStorage, sessionStorage, IndexedDB, cookies, account APIs, or network uploads are used. Export is an explicit local download. The sanitized log excludes Gamepad/HID names, serial numbers, vendor/product IDs, report IDs, and report bytes.
